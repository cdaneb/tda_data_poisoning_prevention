\block[titleleft,roundedcorners=16]{Motivation}{
    \bodyfont\raggedright
    \begin{itemize}
        \item Network intrusion detectors learn from traffic data which is labeled during training.
        \item \textbf{Data poisoning} can inject attack-derived packets with benign labels, shifting the learned decision boundary before deployment.
    \end{itemize}


    \begin{center}
        \includegraphics[width=0.99\linewidth]{Figures/figure_v5_nids_poisoning}
    \end{center}
    \captionfont\raggedright\smallbody
    \textbf{Figure 1.} Mislabeled attacks move the fitted boundary, allowing later attacks to fall on the benign side.

    \vspace{0.20cm}
    \bodyfont\raggedright
    \begin{itemize}
        \item Monkam et al.\ [1] develop a pre-training defense that represents packet payloads with persistent homology and clusters those vectors with OPTICS.
        \item Their methods, using byte permutations, creates a blind spot where certain types of data poisoning attacks are guaranteed to go undetected.
    \end{itemize}

}

\block[titleleft,roundedcorners=16]{Persistent Homology}{
    \bodyfont\raggedright
    Persistent homology follows connected components ($H_0$) and loops ($H_1$)
    as a scale parameter changes; long intervals encode durable shape.

    \begin{center}
        \includegraphics[width=\linewidth]{Figures/figure_v1_tda_background}
    \end{center}
    \captionfont\raggedright\smallbody
    \textbf{Figure 2.} Point-clouds and barcode plots demonstrating persistence in an example 2D dataset.
}

\block[titleleft,roundedcorners=16]{TDA Pipeline}{
    \smallbody
    Per network packet:
    \innerblock{}{
        \centering
        1,500 payload bytes
        $\longrightarrow$ 30 $\times$ 50 raster
        $\longrightarrow \mathrm{Bin}_t$\\[0.12cm]
        $\longrightarrow$ 5 filtrations
        $\longrightarrow (H_0,H_1)$
        $\longrightarrow$ 60 features
        $\longrightarrow$ OPTICS
    }
    \raggedright
    Two height and three radial filtrations feed cubical persistence, scaling,
    persistence entropy, and five amplitude summaries. A packet is captured
    only when OPTICS places it in a non-noise cluster that is 100\% poison.

    \[\]

    \blocksubheading{Controlled Comparison}

    \[\]

    \smallbody\raggedright
    \begin{itemize}
        \item 5,000 clean $+$ 500 poison packets in every cell.
        \item Four permutation families: 
        \begin{itemize}
            \item Transpositions (Swap 60 pairs of random bytes)
            \item Block Reversal (Mirror 120-byte block)
            \item Block Swap (Swap two 60-byte blocks)
            \item Cyclic Shift (Rotate every row by 1 index)
        \end{itemize}
        \item Five fixed seeds; attacks are required to change the raw byte vector.
        \item $\pm$ values are population standard deviation (SD). Ground-truth labels are
        used for scoring only.
    \end{itemize}
    
}

\block[titleleft,roundedcorners=16]{Methods}{
    \bodyfont\raggedright
    Let $\mathlarger{z_i=x_i/M}$ be a payload byte normalized by the fitted batch maximum. \textbf{Byte permutations preserve $\mathlarger{M}$ because they preserve the batch byte multiset.} Define a binarizer as
    \[
    \mathlarger{\mathlarger{
                \mathrm{Bin}_t(z)_i =
                \begin{cases}
                1, & z_i > t,\\
                0, & z_i \leq t
                \end{cases}
                }}
    \]
    \textbf{Blind-spot}: one cutoff creates two intensity classes.
    If $C_0$ and $C_1$ are the positions not exceeding and exceeding $t=0.4$,
    respectively, then every permutation within either class leaves the binary
    image fixed:
    \[
        \mathlarger{\mathlarger{
        \operatorname{Stab}\!\left(\mathrm{Bin}_{0.4}(z)\right)
        \cong S_{|C_0|}\times S_{|C_1|}.
        }}
    \]
    Thus, whenever either class contains multiple positions, nonidentity byte permutations exist that the pipeline cannot distinguish before any filtration is computed. 

    \[\]
    
    \textbf{Solution: nine thresholds refine two classes into ten
    ordered bands.}
    For $T=\{0.1,0.2,\ldots,0.9\}$, define the nested signature
    \[
        \mathlarger{\mathlarger{
        Q_T(z)_i=\bigl(\mathrm{Bin}_t(z)_i\bigr)_{t\in T}.
        }}
    \]
    If $C_0,\ldots,C_9$ are the ten resulting intensity bands, then
    \[
        \mathlarger{\mathlarger{
        \operatorname{Stab}\!\left(Q_T(z)\right)
        \cong \prod_{k=0}^{9} S_{|C_k|}
        \subseteq \operatorname{Stab}\!\left(\mathrm{Bin}_{0.4}(z)\right).
        }}
    \]

    \raggedright
    The stack repairs the single-threshold blind spot by shrinking its guaranteed-invisible group. It still cannot distinguish permutations within one band, and persistence
    is not injective, so the argument does not guarantee universal detection.
}

\block[titleleft,roundedcorners=16]{Implementation}{
    \bodyfont\raggedright
    \textbf{Control}
    \[
        \mathlarger{\mathlarger{
        F_{0.4}(x)\in\mathbb{R}^{60}.
        }}
    \]
    \textbf{Repair}
    \[
        \mathlarger{\mathlarger{
        F_T(x)=\frac{1}{\sqrt{9}}
        \bigl(F_{0.1}(x),\ldots,F_{0.9}(x)\bigr)
        \in\mathbb{R}^{540}.
        }}
    \]
    Each $\mathlarger{F_t}$ is the unchanged $60$-feature pipeline. Division by $\mathlarger{\sqrt{9} = 3}$
    preserves scale in the reference case where all nine blocks are identical. All other variables (filtrations, rasterized image, OPTICS specifications) kept constant.
}

\block[titleleft,roundedcorners=16]{Conclusion and Future Work}{
    \bodyfont\raggedright
    \begin{itemize}
        \item The threshold stack preserves permutation-induced changes that one singular threshold erases.
        \item  Under the current pipeline, even with multiple thresholds, clustering-based poisoning removal does not materially improve.
    \end{itemize}
    $\therefore$ Future work must address discrepancies in the local geometry to assist clustering and improve actual poisoning detection.
}
