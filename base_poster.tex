    \smallbody\raggedright

    labels, shifting a learned decision boundary before deployment.
    Monkam et al.\ [1] propose an upstream TDA--OPTICS filter to identify
    poisoned packets before model fitting.

\block[titleleft,roundedcorners=12]{Reconstruction and Controlled Test}{
    \smallbody\raggedright

    \textbf{Data:} UNSW-NB15 Payload-Byte [2].

    \innerblock{}{
        \centering
        1,500 bytes
        $\to$ 30 $\times$ 50 raster
        $\to \mathrm{Bin}_t$
        $\to$ 2 height $+$ 3 radial filtrations
        $\to$ cubical persistence $(H_0,H_1)$
        $\to \mathbb{R}^{60}$
        $\to$ OPTICS
    }

    \begin{itemize}
        \item Four probe families $\times$ five fixed seeds; each cell has
        5,000 clean $+$ 500 poison packets. Values $=$ means
        $\pm$ population SD.

        \item 4 permutation families: Transpositions (Swap 60 pairs of random bytes), Block Reversal (Mirror 120-byte block), Block Swap (Swap two 60-byte blocks), Cyclic Shift (Rotate every row by 1 index).

        \item Every probe changes the raw vector and preserves its byte multiset.
        \item Ground-truth labels are used for scoring only.
    \end{itemize}
}

\block[titleleft,roundedcorners=12]{Why One Cutoff Loses Information}{
    \theorybody\raggedright

    One network packet (Payload Byte) from UNSW-NB15 is represented by $x\in\{0,\ldots,255\}^{n}$, $n=1{,}500$. \\ The maximum byte value
    $M$ is defined as $\max_i x_i = 255$; each byte is then normalized $z=x/M\in[0,1]^{n}$. \\ Define the binarizer at threshold $t$ by
    \[
        \mathrm{Bin}_t(z)_i=
        \begin{cases}
            1, & z_i>t,\\[0.06cm]
            0, & z_i\leq t.
        \end{cases}
    \]
    Let $\sigma\in S_n$ permute byte positions. Since $\sigma$ preserves the
    byte multiset it fixes $M$, so $\sigma z=(\sigma x)/M$ and
    \[
        \mathrm{Bin}_t(\sigma z)=\sigma\,\mathrm{Bin}_t(z).
    \]

    Original pipeline uses a single cutoff, $t=0.4$:
    \[
        A^-=\{i:z_i\leq0.4\},
        \qquad
        A^+=\{i:z_i>0.4\}.
    \]
    Any permutation that acts within these two classes leaves the
    binarization unchanged, so the stabilizer of $z$ is contained in the
    stabilizer of its binarization:
    \[
        G_z:=\operatorname{Stab}(z)
        \;\leq\;
        G_{0.4}:=\operatorname{Stab}\bigl(\mathrm{Bin}_{0.4}(z)\bigr)
        \;=\;S(A^-)\times S(A^+).
    \]
    \begin{center}
        \textbf{Blind spot}: $G_{0.4}\setminus G_z$.
    \end{center}

    Solution: nine thresholds $T=\{0.1,\ldots,0.9\}$. Stack the binarizers
    into a per-position signature
    \[
        Q_T(z)_i=\bigl(\mathrm{Bin}_t(z)_i\bigr)_{t\in T}\in\{0,1\}^{9},
    \]
    and let $B_k$ collect the positions whose signature has exactly $k$
    ones, so $z_i\in\bigl(\tfrac{k}{10},\tfrac{k+1}{10}\bigr]$. The
    stabilizer shrinks to
    \[
        G_z
        \;\leq\;
        G_T:=\operatorname{Stab}\bigl(Q_T(z)\bigr)
        \;=\;\prod_{k=0}^{9}S(B_k)
        \;\leq\;G_{0.4}.
    \]

    \vspace{0.12cm}

    {\color{MyTerracotta}\bfseries
    \begin{center}
        Reducing representation invariance does not guarantee detection, but probability decreases substantially.
    \end{center}\par}
}

\block[titleleft,roundedcorners=12]{Conclusion and Scope}{
    \smallbody\raggedright

    \begin{itemize}
        \item Nine thresholds reduce exact poison--clean collisions by
        92--96\% among raw-changing poison packets, confirming that the
        single-cutoff blind spot is real and closable.

        \item Closing it does \textbf{not} improve detection. The
        540-dimensional representation mainly fragments the OPTICS
        clustering, so poison packets are labeled noise rather than
        recovered as a cluster.

        \item Future work should improve attack separation relative to
        ordinary clean variation before retuning or replacing OPTICS.
    \end{itemize}
}
