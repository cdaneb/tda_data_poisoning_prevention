\block[titleleft,roundedcorners=12]{Motivation}{
    \smallbody\raggedright
    Training-set poisoning can insert attack-derived traffic with benign labels,
    shifting a learned decision boundary before deployment. Monkam et al.\ [1]
    propose an upstream TDA--OPTICS filter to identify poisoned packets before
    model fitting.

    \vspace{0.08cm}
    {\centering
        \includegraphics[width=0.82\linewidth]{figures/figure_v5_nids_poisoning}\par
    }
    \captionfont\raggedright
    \textbf{Figure 1.} Conceptual motivation only: mislabeled attacks can shift
    a learned boundary. The experiments below evaluate the upstream filter, not
    classifier retraining.
}

\block[titleleft,roundedcorners=12]{Persistent Homology}{

    \vspace{0.08cm}
    {\centering
        \includegraphics[width=0.84\linewidth]{figures/figure_v1_tda_background}\par
    }
    \captionfont\raggedright
    \textbf{Figure 2.} Point-cloud neighborhoods and the corresponding

}

\block[titleleft,roundedcorners=12]{Reconstruction and Controlled Test}{
    \smallbody\raggedright
    \textbf{Data:} UNSW-NB15 Payload-Byte [2].
    \innerblock{}{
        \centering
        1,500 bytes $\to$ 30 $\times$ 50 raster $\to \mathrm{Bin}_t$
        $\to$ 2 height $+$ 3 radial filtrations\\[0.04cm]
        $\to$ cubical persistence $(H_0,H_1)$ $\to \mathbb{R}^{60}$ $\to$ OPTICS
    }

    \begin{itemize}
        \item Four probe families $\times$ five fixed seeds; each cell has
        5,000 clean $+$ 500 poison packets. Values are means $\pm$ population SD.
        \item Probes use 60 disjoint transpositions, one 120-byte reversal, two
        swapped 60-byte blocks, or a nonzero prefix rotation.
        \item Every probe changes the raw vector and preserves its byte multiset.
        Only the threshold representation changes; packet pairs and downstream
        settings are fixed.
    \end{itemize}

    \textbf{Retrospective capture:} poison assigned to a non-noise cluster
    containing no clean packet. Ground-truth labels are unavailable to a
    deployed filter.
}

\block[titleleft,roundedcorners=12]{Why One Cutoff Loses Information}{
    \smallbody\raggedright
    Let $z=x/M$, and let $S_n$ permute byte positions. Permutations preserve
    the fitted maximum $M$, so thresholding
    $\mathrm{Bin}_t(z)_i=\mathbf{1}\{z_i>t\}$ is equivariant. At $t=0.4$, let
    $A^-=\{i:z_i\leq0.4\}$ and $A^+=\{i:z_i>0.4\}$. Then
    \[
        G_z:=\operatorname{Stab}(z)
        \leq
        G_{0.4}:=\operatorname{Stab}(\mathrm{Bin}_{0.4}(z))
        =S(A^-)\times S(A^+).
    \]
    The meaningful blind spot is $G_{0.4}\setminus G_z$: raw-changing
    permutations erased by the cutoff. It is nonempty precisely when one
    threshold class contains two distinct byte values.

    \vspace{0.08cm}
    For $T=\{0.1,\ldots,0.9\}$, define
    $Q_T(z)_i=(\mathrm{Bin}_t(z)_i)_{t\in T}$. If
    $B_0,\ldots,B_9$ are the induced bands, then
    \[
        G_z
        \leq
        G_T:=\operatorname{Stab}(Q_T(z))
        =\prod_{k=0}^{9}S(B_k)
        \leq G_{0.4}.
    \]
    The final containment is strict when an occupied $0.4$ class spans multiple
    bands. Within-band permutations and later noninjective maps can still create
    collisions. Thus the stack reduces representation invariance; it does not
    guarantee detection.

    \vspace{0.08cm}
    \innerblock{Controlled representation change}{
        \captionfont\raggedright
        \[
            \begin{aligned}
            \text{Control: }&F_{0.4}(x)\in\mathbb{R}^{60},\\
            \text{Repair: }&F_T(x)=\frac{1}{\sqrt{9}}
            \bigl(F_{0.1}(x),\ldots,F_{0.9}(x)\bigr)\in\mathbb{R}^{540}.
            \end{aligned}
        \]
        Each $F_t$ uses the same 60-feature pipeline. The same packet pairs enter
        both arms; $1/\sqrt{9}$ matches a single-block Euclidean distance only
        when all nine blockwise differences are identical.
    }
}

\block[titleleft,roundedcorners=12]{Conclusion and Scope}{
    \smallbody\raggedright
    \begin{itemize}
        \item Nine thresholds reduce exact poison--clean collisions by 92--96\%.
        \item Matched-cost capture does \textbf{not} materially improve.
        \item The repair mainly fragments OPTICS output: poison assigned the
        noise label $-1$ rises from 85--87\% to about 99\%, clean assigned $-1$
        from 37\% to 55\%, and mean cluster count falls from about 140 to 108.
        \item Next work should improve attack separation relative to ordinary
        clean variation before retuning or replacing OPTICS.
    \end{itemize}

    \captionfont\raggedright
    \textbf{Scope.} We evaluate a 60-feature reconstruction ([1] reports 72) on
    UNSW-NB15 using four synthetic byte-permutation probes over five seeds.
    Protocol validity and retained attack functionality were not tested. Cluster
    purity uses ground truth retrospectively and is not deployable. The proof
    establishes reduced representation invariance, not universal detection.
}
